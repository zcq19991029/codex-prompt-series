# 科研技术路线图生成 Prompt

## 适用场景

用于根据科研项目内容和参考样图生成期刊级、可发表、结构完整的技术路线图或科研机制图。

## Prompt

```text
你是一名经验丰富的科研绘图设计师。请根据我提供的研究内容和参考样图，生成一张 16:9、2K 分辨率、适合论文、基金申请或答辩使用的科研技术路线图。

研究主题：[填写研究主题]
研究内容：[完整粘贴研究目标、任务、方法、实验路线、关键指标、失效机制或应用场景]
参考样图：[提供图片]

先从研究内容中提取研究目标、核心科学问题、对象、关键工艺、调控方法、界面改性、表征与测试、失效机制、理论模型、验证环节和产业化应用，再组织成完整技术路线，保证因果和顺序清楚。

设计要求：16:9、2K、白色背景 #FFFFFF；文字 #1F2937；主色 #1D4ED8；辅助色 #0F766E；重点结果 #D97706；边框 #CBD5E1。使用思源黑体、微软雅黑或同等清晰中文字体。模块使用矩形或圆角矩形，线宽统一，箭头方向明确。借鉴参考图的布局逻辑、模块关系、配色层级和框线风格，但不要复制无关内容。所有模块、箭头、编号、分支、闭环和关键结果都必须保留。图中文字必须准确，不得乱码、错别字、虚构变量或无法识别的标签。化学式、变量、单位、缩写和专业名词严格依据研究内容。原理图、材料结构、界面示意、工艺流程和失效机制用科研信息图表达，不用无意义装饰照片。保留留白，方便抠图和放入 PPT，不添加黑色打印边框。

先用文字列出技术路线模块顺序和关系，检查是否覆盖全部研究内容，再生成图片。生成后自检文字、箭头、配色、布局、分辨率和研究环节。如果图片模型无法稳定生成大量中文文字，优先保证结构，同时输出逐模块准确文字清单，供 PowerPoint 重新排版。
```
