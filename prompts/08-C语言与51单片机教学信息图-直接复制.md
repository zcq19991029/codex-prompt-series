【五、C语言知识严谨性】
━━━━━━━━━━━━━━━━━━

1. 所有知识解释必须符合C语言/C51实际规则。
2. 不要为了“通俗”而说错。
3. 如果是简化教学，要在不改变核心规则的前提下简化。
4. 真/假判断：

表达式值 ≠ 0
→ 真

表达式值 = 0
→ 假

5. if语句：

if(表达式)
{
    语句组;
}

条件非0：
执行语句组。

条件为0：
跳过语句组。

6. while：

先判断，
后执行。

7. do-while：

先执行，
后判断。

8. for循环真实顺序必须正确：

表达式1
↓
表达式2
↓
条件成立？
↓
循环体
↓
表达式3
↓
回到表达式2

9. break：
退出当前所在的、离它最近的一层循环或switch。

10. continue：
跳过本轮剩余代码，进入下一轮循环。

11. switch：
先计算switch括号中表达式的值，再寻找匹配case。

12. case：
决定从哪里开始执行。

13. break：
决定在哪里停止继续向下执行。

14. 不要错误写成：
“每个case后必须有break”。

正确表述：

“一般独立分支后写break，避免继续向下执行；
某些场合可以故意省略break。”

15. default不是必须的。
16. default通常放最后，但不是语法上强制必须放最后。
17. default放在最后时，最后一个break可以省略，也可以保留。
18. 浮点常量要严谨：
标准C中：

3.14
默认是double。

3.14f
或
3.14F
才明确是float。

19. 字符与字符串必须区分：

'A'
→ 字符

"A"
→ 字符串

20. 字符串末尾自动带：

'\0'

21. 对于本套51单片机教学中的移位，
如果讲右移，统一按 unsigned 无符号数举例，
避免有符号数右移造成歧义。

22. 无符号右移：

低位移出丢弃，
高位补0。

23. 左移：

高位移出丢弃，
低位补0。

24. return：
用于把结果返回调用位置。

25. void：
前面的void表示“不返回结果”；
括号里的void表示“不接收参数”。

例如：

void led_crol(void)

前一个void：
函数不返回结果。

后一个void：
函数不接收参数。

【六、流程图要求】

8. 开始/结束可以使用圆角框。
9. 真分支和假分支必须明确区分。
10. 多分支结构必须表现成：

条件1
↓
如果真 → 执行事件1 → 离开选择结构

如果假
↓
继续判断条件2

条件2真
→ 执行事件2

条件2假
↓
继续往下判断

不能错误画成：
“从假分支直接当成下一次判断结果”。

11. if单分支：

条件真
→ 执行语句组

条件假
→ 直接绕过

两条路线最后继续汇合。

12. if-else双分支：

条件
├─ 真 → 语句组1
└─ 假 → 语句组2

最后汇合。

13. else-if多分支：
必须突出：

从上到下依次判断，
找到第一个成立的条件，
执行对应分支，
然后离开整个选择结构。

14. 循环流程图必须画出“回去重新判断”的回路。
15. 不允许只画向下箭头而漏掉循环回路。
