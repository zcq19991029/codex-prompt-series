# Prompt 系列

面向 Codex、Claude Code 和其他代码智能体的可复用项目协作 Prompt。

这个仓库不保存某个具体项目的代码，而是保存可以复制到新聊天窗口使用的工作模板。每个 Prompt 都尽量说明适用场景、输入信息、执行顺序、文档要求和验收标准。

## 目录

| 目录 | 内容 |
|---|---|
| `prompts/` | 可直接复制使用的 Prompt |
| `.agents/skills/` | 教学图规划、生成、模板合成、复刻四个可复用 Skill |
| `CHANGELOG.md` | 版本和内容变更记录 |

## 教学图四阶段流程

也可直接调用对应 Skill：

| 阶段 | 调用 | 依据与依赖 |
|---|---|---|
| 规划 | `$teach-1-plan` | 09 工作流，配套生成技能提供完整视觉规范 |
| 生成 | `$teach-2-gen` | 08 生图全文，调用公共 imagegen |
| 嵌图合成 | `$teach-3-embed` | 10 模板合成要求，复用PPT读写和渲染能力 |
| 复刻 | `$teach-4-ppt` | 08 重建要求，调用公共 image-to-editable-ppt |

技能真实文件位于本仓库 .agents/skills，各技能仅含 SKILL.md、界面元数据及确有需要的参考文件，不另建技能 README。提示词仍保留，适合未安装 Skill 的工具直接复制。
仓库内的四个技能应配套使用；在其他项目调用前，将其安装或链接到该环境的技能发现目录。仓库文件存在不等于当前聊天已经载入，创建后在新聊天检查技能列表；未发现时可明确要求读取对应 SKILL.md。
示例：“用 $teach-1-plan 先只给图数量、标题和拆分说明，等我确认增减”；确认后编写并保存完整提示词，回复“生成”再用 $teach-2-gen 逐张读文件生图；新聊天可选用 $teach-4-ppt 逐图复现。
完整提示词按“标题-提示词.md”保存，并建立提示词索引.md；生成时读取当前完整文件与素材，保存检查后再处理下一图，记录输入版本/SHA-256与输出，避免凭聊天记忆改写。默认聊天只给索引与概览，要求全文时再展示。生成技能规范与08保持一致；规划与复刻技能不复制公共工具后端。
验证包括 skill-creator 的 quick_validate、YAML、相对引用及规范正文一致性；已有真实12页嵌图展示验收，第四阶段可编辑复刻尚未完成。

1. 提示词1：复制09并上传PPT，先取得图数量、标题、拆分理由和覆盖说明；确认增减与文件夹名后才编写并落盘完整提示词。
2. 提示词2：08是生图规范，融合于每图完整文件；收到生成回复后逐张读取文件并生成，默认使用执行时最新可用模型，说明官方最新与当前实际可调用版本。
3. 提示词3：复制10，将确定版本图片按模板合成为展示版PPT，输出到图片任务文件夹。
4. 提示词4：在同项目的新聊天复制 08 的第二个代码块，附原图、复现清单、复现交接和必要模板，调用公共 Skill 忠实重建可编辑 PPT。

新聊天仍遵守项目规则，复刻依据来自交接文件，不依赖规划聊天的长期记忆。模型版本以实际工具能力为准，不硬编码未经核实的“最新”型号。

截图内文字、代码和公式可按需OCR辅助核对，参考image-to-editable-ppt的已有识别流程；原生提取优先、结果对照原图，不自动启动复刻或强制整套OCR。公开安装包与完整短调用说明见 [可编辑教学图](https://github.com/zcq19991029/editable-teaching-graphics)，本仓库维护原件，发布包按版本同步。

## 第三阶段：模板嵌图合成

生图完成后可在同一聊天调用 `$teach-3-embed`。模板合成按已确认顺序匹配标题和图片，保留模板装饰，完整等比放图、底端对齐并保护横线。标题可编辑，图内内容仍为图片。对象级可编辑复刻顺延为第四阶段 `$teach-4-ppt`，按需在新聊天执行。

```text
用 $teach-3-embed 合成这套确定版本教学图。
模板：[填写模板路径；未指定时检查生图工作区的嵌图模板.pptx]
图片与顺序：[填写图片任务文件夹或索引路径]
每图一页，填写对应标题；图片等比、底端对齐，上端在模板横线下方且不遮挡横线。
PPTX保存在同一个图片任务文件夹内，检查结论并入生成记录；临时预览检查后清理，保留原图与模板。
```

默认共享模板为“生图/嵌图模板.pptx”；输出为“生图/用户命名任务文件夹/任务名-嵌图版.pptx”。比例造成的小间隙如实记录，不裁切、拉伸或假称完全贴齐。页数由确定版图片清单决定。

## PPT参考、原创插图与当前提示词

PPT提供教学依据，生图阶段默认重新设计教学表达，不要求外观相似。参考图片分为内容依据、对象外观参考、风格参考、用户明确指定原样保留的复用素材；只有最后一类必须忠实复用。普通原图可以重绘或替换成原创设备、情境、流程或视觉比喻，原页没有插图也应正常生成，不必等待素材。

创新范围包括构图、插图、主题内解释、通俗改写和视觉叙事；评分数字、代码、公式、技术条件和逻辑关系保持准确。版式与颜色建议留有空间，不强制每张都用彩色卡片。生成设备和作品是示意，不冒充真实学生成果。只有第四阶段teach-4-ppt才忠实复刻已经确定的教学图。

每图当前完整提示词集中放在任务目录的提示词/标题-提示词.md，本地只保留一个当前文件，不默认生成历史版本或备份目录。修订更新当前文件和索引，生成记录保留实际提交版本及SHA-256。用户授权清理后，只删除确认属于旧提示词的文件；原PPT、参考素材、图片成品和运行记录不随之清理。

第一次使用请先看 [开始使用.md](开始使用.md)。

## 使用方式

1. 打开目标项目或准备创建项目的聊天窗口。
2. 复制对应 Prompt。
3. 填写项目名称、目标和路径等占位信息。
4. 让智能体先分析和建立文档，再开始实现代码。

Prompt 是工作模板，不替代项目自身的 `AGENTS.md`、`README.md` 或测试结果。使用时仍应核对实际文件。

## 添加新 Prompt

新增 Prompt 时：

- 延续 `编号-中文主题-直接复制.md` 命名，便于查找和复制。
- 在文件开头写明用途、适用场景和不适用场景。
- 使用占位符表示需要用户填写的信息。
- 写清楚输出物、验证方式和失败时如何报告。
- 在本 README 的“当前 Prompt”表中登记。
- 在 `CHANGELOG.md` 记录变更。

## 完整复刻调用：路径与输出选择

简短调用只给复现交接.md路径并非缺少能力：交接必须能定位全部资料和明确输出要求。为了方便首次使用和跨电脑迁移，推荐复制下面的完整模板，将已知实际路径直接填好；不必手动粘贴每份清单正文。可选项明确填“无”，交接中已有完整字段时也可注明“从交接读取”。未决定的合并方式、模板或输出位置标为待确认，不能冒充已选定。

```text
用 $teach-4-ppt 忠实复刻这套确定版本教学图，制作对象级可编辑PPT。

项目根目录：[绝对路径]
复现交接文件：[复现交接.md的绝对路径]
总索引：[提示词索引.md的绝对路径]
原图目录：[图片目录的绝对路径]
逐图复现清单目录：[复现清单目录的绝对路径]
必要独立素材：[目录路径；没有则填“无”，不得凭空补素材]
模板：[PPT模板绝对路径；没有则填“无”，按原图比例]
已有嵌图展示版：[PPT路径；没有则填“无”，仅供标题及排版参考]
生成与检查记录：[生成记录.md的绝对路径]
复刻范围：[全部／索引中的指定编号]
输出形式：[每图分别输出／按索引顺序合并为一个PPTX]
输出目录：[复现子项目下的任务目录绝对路径]
合并文件名：[选择合并时填写；分别输出则使用各图确认标题]

先核对项目规则、输入文件及索引中标题与图片、提示词、清单的对应。
以最终原图为布局和插图依据，以复现清单校对准确文字、数字和关系。
普通文字、代码、表格、卡片及连线重建为原生对象，复杂插图可忠实分离为独立图片。
保留原图比例，按模板主体区放置；禁止整图铺底覆盖文字的伪可编辑。
输出仅写指定复现目录，保留生图原图和已有展示版。
按公共image-to-editable-ppt技能完成验收，交付PPT及必要验证材料，说明编辑范围和差异。
若显式填写的路径或输出选择与交接冲突，先指出并解决；不得静默改选。
无需读取规划聊天历史。
```

生图阶段完成交接时，应同时给用户一段已填写真实路径的调用语句，包含总索引、原图、复现清单、模板和输出目录，输出方式未定时明确提示待选。共享模板不等于现有嵌图PPT使用过的同一版本，必要时核对版本差异。

## 当前项目目录架构

以下为实际有任务时的参考结构，按需创建，不预建空目录。嵌图展示和对象级复刻分别归生图与复现子项目；根目录只维护AGENTS，不新增总README或总交接。

```text
教学主题项目/
├── AGENTS.md                     父目录共用规则
├── .agents/skills/               可选技能链接入口，不放任务素材
├── 生图/
│   ├── README.md、项目交接.md     子项目长期说明与当前状态
│   ├── 嵌图模板.pptx             共享模板，实际需要时提供
│   └── 用户命名的任务文件夹/
│       ├── 输入/                 原始PPT
│       ├── 参考素材/             确有需要的来源资料和独立素材
│       ├── 提示词/               标题-提示词.md，每图一个当前文件
│       ├── 图片/                 标题.png，保存确定版本
│       ├── 复现清单/             标题-复现清单.md，准确内容及关系
│       ├── 生图规划.md            数量、拆分理由和原页覆盖
│       ├── 提示词索引.md          唯一总表：顺序、标题、路径、尺寸、哈希
│       ├── 生成记录.md            生成、修订及嵌图检查结论
│       ├── 复现交接.md            引用总索引，补充模板及复刻约束
│       └── 任务名-嵌图版.pptx     第三阶段展示版，完成后才存在
└── 复现/                         启动第四阶段后才建立任务
    ├── README.md、项目交接.md
    └── 对应任务文件夹/
        ├── 任务名-可编辑版.pptx   合并输出，或分别输出标题.pptx
        └── 必要验收及运行资料     遵循公共复刻技能要求
```

嵌图检查用截图、预览和操作JSON放任务临时目录，成功并记录检查结果后清理，不作为默认交付；失败时按需留证据。复刻阶段仍遵循公共技能的验收要求。仅维护一份总索引，不另建图片与提示词对应清单。
