# Prompt 系列

面向 Codex、Claude Code 和其他代码智能体的可复用项目协作 Prompt。

这个仓库不保存某个具体项目的代码，而是保存可以复制到新聊天窗口使用的工作模板。每个 Prompt 都尽量说明适用场景、输入信息、执行顺序、文档要求和验收标准。

## 目录

| 目录 | 内容 |
|---|---|
| `prompts/` | 可直接复制使用的 Prompt |
| `.agents/skills/` | 教学图规划、生成、复刻三个可复用 Skill |
| `CHANGELOG.md` | 版本和内容变更记录 |

## 教学图三阶段流程

也可直接调用对应 Skill：

| 阶段 | 调用 | 依据与依赖 |
|---|---|---|
| 规划 | `$teach-1-plan` | 09 工作流，配套生成技能提供完整视觉规范 |
| 生成 | `$teach-2-gen` | 08 生图全文，调用公共 imagegen |
| 复刻 | `$teach-3-ppt` | 08 重建要求，调用公共 image-to-editable-ppt |

技能真实文件位于本仓库 .agents/skills，各技能仅含 SKILL.md、界面元数据及确有需要的参考文件，不另建技能 README。提示词仍保留，适合未安装 Skill 的工具直接复制。
仓库内的三个技能应配套使用；在其他项目调用前，将其安装或链接到该环境的技能发现目录。仓库文件存在不等于当前聊天已经载入，创建后在新聊天检查技能列表；未发现时可明确要求读取对应 SKILL.md。
示例：“用 $teach-1-plan 先只给图数量、标题和拆分说明，等我确认增减”；确认后编写并保存完整提示词，回复“生成”再用 $teach-2-gen 逐张读文件生图；新聊天可选用 $teach-3-ppt 逐图复现。
完整提示词按“标题-提示词.md”保存，并建立提示词索引.md；生成时读取当前完整文件与素材，保存检查后再处理下一图，记录输入版本/SHA-256与输出，避免凭聊天记忆改写。默认聊天只给索引与概览，要求全文时再展示。生成技能规范与08保持一致；规划与复刻技能不复制公共工具后端。
验证包括 skill-creator 的 quick_validate、YAML、相对引用及规范正文一致性；尚未以真实 PPT 执行三阶段验收。

1. 提示词1：复制09并上传PPT，先取得图数量、标题、拆分理由和覆盖说明；确认增减与文件夹名后才编写并落盘完整提示词。
2. 提示词2：08是生图规范，融合于每图完整文件；收到生成回复后逐张读取文件并生成，默认使用执行时最新可用模型，说明官方最新与当前实际可调用版本。
3. 提示词3：在同项目的新聊天复制 08 的第二个代码块，附原图、复现清单、复现交接和必要模板，调用公共 Skill 忠实重建可编辑 PPT。

新聊天仍遵守项目规则，复刻依据来自交接文件，不依赖规划聊天的长期记忆。模型版本以实际工具能力为准，不硬编码未经核实的“最新”型号。

截图内文字、代码和公式可按需OCR辅助核对，参考image-to-editable-ppt的已有识别流程；原生提取优先、结果对照原图，不自动启动复刻或强制整套OCR。公开安装包与完整短调用说明见 [可编辑教学图](https://github.com/zcq19991029/editable-teaching-graphics)，本仓库维护原件，发布包按版本同步。

第一次使用请先看 [开始使用.md](开始使用.md)。

## 使用方式

1. 打开目标项目或准备创建项目的聊天窗口。
2. 复制对应 Prompt。
3. 填写项目名称、目标和路径等占位信息。
4. 让智能体先分析和建立文档，再开始实现代码。

Prompt 是工作模板，不替代项目自身的 `AGENTS.md`、`README.md` 或测试结果。使用时仍应核对实际文件。

## 添加新 Prompt

新增 Prompt 时：

- 延续 `编号-中文主题-直接复制.md` 命名，便于查找和复制。
- 在文件开头写明用途、适用场景和不适用场景。
- 使用占位符表示需要用户填写的信息。
- 写清楚输出物、验证方式和失败时如何报告。
- 在本 README 的“当前 Prompt”表中登记。
- 在 `CHANGELOG.md` 记录变更。
