# Prompt 系列

面向 Codex、Claude Code 和其他代码智能体的可复用项目协作 Prompt。

这个仓库不保存某个具体项目的代码，而是保存可以复制到新聊天窗口使用的工作模板。每个 Prompt 都尽量说明适用场景、输入信息、执行顺序、文档要求和验收标准。

## 目录

| 目录 | 内容 |
|---|---|
| `prompts/` | 可直接复制使用的 Prompt |
| `CHANGELOG.md` | 版本和内容变更记录 |

## 教学图三阶段流程

1. 提示词1：复制 09，上传 PPT，先取得拆解规划和逐图完整提示词。
2. 提示词2：08 的第一个代码块是生图规范；09 将其完整融合到每图提示词。确认数量、标题、内容和文件夹名称后逐图生成。
3. 提示词3：在同项目的新聊天复制 08 的第二个代码块，附原图、复现清单、复现交接和必要模板，调用公共 Skill 忠实重建可编辑 PPT。

新聊天仍遵守项目规则，复刻依据来自交接文件，不依赖规划聊天的长期记忆。模型版本以实际工具能力为准，不硬编码未经核实的“最新”型号。

第一次使用请先看 [开始使用.md](开始使用.md)。

## 使用方式

1. 打开目标项目或准备创建项目的聊天窗口。
2. 复制对应 Prompt。
3. 填写项目名称、目标和路径等占位信息。
4. 让智能体先分析和建立文档，再开始实现代码。

Prompt 是工作模板，不替代项目自身的 `AGENTS.md`、`README.md` 或测试结果。使用时仍应核对实际文件。

## 添加新 Prompt

新增 Prompt 时：

- 延续 `编号-中文主题-直接复制.md` 命名，便于查找和复制。
- 在文件开头写明用途、适用场景和不适用场景。
- 使用占位符表示需要用户填写的信息。
- 写清楚输出物、验证方式和失败时如何报告。
- 在本 README 的“当前 Prompt”表中登记。
- 在 `CHANGELOG.md` 记录变更。
